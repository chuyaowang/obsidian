## Heterogeneous graph

A heterogeneous graph is a graph that contains **multiple types of nodes and/or multiple types of edges**, each with their own feature spaces, semantics, and relationships. These graphs cannot be represented with a single node feature matrix or a single edge index because different types have different attributes and dimensionalities.

### 🧩 What defines a heterogeneous graph

A graph is heterogeneous when **either** of the following is true:

- It has **different node types** (e.g., authors, papers, institutions), each with their own features.
- It has **different edge types** (e.g., *writes*, *cites*, *affiliated_with*), each representing a different relation.

Because of this, message passing must be conditioned on node/edge type, and PyG uses `HeteroData` to store separate feature tensors for each type.

### 📚 Examples of heterogeneous graphs

- **Academic networks** (e.g., OGBN-MAG):  
  Node types: *paper*, *author*, *institution*, *field of study*  
  Edge types: *writes*, *cites*, *affiliated_with*, *has_topic*   [pytorch-geometric.readthedocs.io](https://pytorch-geometric.readthedocs.io/en/latest/tutorial/heterogeneous.html)
- **Recommendation systems**:  
  Nodes: *users*, *items*  
  Edges: *purchased*, *viewed*, *rated*
- **Knowledge graphs**:  
  Nodes: *entities*  
  Edges: *relations* like *born_in*, *located_in*, *works_at*
- **Social platforms with multiple entity types**:  
  Nodes: *users*, *posts*, *hashtags*  
  Edges: *follows*, *likes*, *tags*

### A compact way to think about it

A heterogeneous graph is really multiple graphs overlaid on the same set of entities, each representing a different relation. Each relation needs its own adjacency (edge_index) because:

- it connects different node types,
- it has different edges,
- and it uses different message/update functions.

## Example: ogbn-mag network

- Node types: author, paper, institution, and field of study
- Edge types: 
	- writes: An author writes a specific paper
	- affiliated with: An author is affiliated with a specific institution
	- cites: A paper cites another paper
	- has topic: A paper has a topic of a specific field of study
- Task: predict if the paper is published in a journal or a conference

### Defining a heterogeneous graph

The node features, edge indices, and edge attributes for the typed nodes and edges can be built as follows:

``` python
from torch_geometric.data import HeteroData

data = HeteroData()

data['paper'].x = ... # [num_papers, num_features_paper]
data['author'].x = ... # [num_authors, num_features_author]
data['institution'].x = ... # [num_institutions, num_features_institution]
data['field_of_study'].x = ... # [num_field, num_features_field]

data['paper', 'cites', 'paper'].edge_index = ... # [2, num_edges_cites]
data['author', 'writes', 'paper'].edge_index = ... # [2, num_edges_writes]
data['author', 'affiliated_with', 'institution'].edge_index = ... # [2, num_edges_affiliated]
data['paper', 'has_topic', 'field_of_study'].edge_index = ... # [2, num_edges_topic]

data['paper', 'cites', 'paper'].edge_attr = ... # [num_edges_cites, num_features_cites]
data['author', 'writes', 'paper'].edge_attr = ... # [num_edges_writes, num_features_writes]
data['author', 'affiliated_with', 'institution'].edge_attr = ... # [num_edges_affiliated, num_features_affiliated]
data['paper', 'has_topic', 'field_of_study'].edge_attr = ... # [num_edges_topic, num_features_topic]
```

Node types are indicated with a single string, and edge types are indicated by a triplet o of `(source_node_type, edge_type, destination_node_type)` strings.

To retrieve the feature matrix `x`, edge index, and edge features for the whole graph, just add `_dict` to the matrix name. They can also be used directly in GNNs:

``` python
model = HeteroGNN(...)

output = model(data.x_dict, data.edge_index_dict, data.edge_attr_dict)
```
