# Gemini CLI

## Installation

- Installed latest node and npm via standalone installer [Node.js](https://nodejs.org/) 
- Run `npm install -g @google/gemini-cli@latest`

## Install skills

[Full documentation](https://geminicli.com/docs/cli/skills/)
Allows you to install skill files from claude.

```bash
gemini skills install /path/to/local/my-expertise.skill
```
